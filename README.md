## «VK Маруся»

Онлайн-платформа «VK Маруся», на которой пользователи могут находить фильмы и ставить им оценки. Реализована функция поиска по названию, настроена возможность оценки фильмов с отправкой данных на сервер, а также обеспечена интуитивно понятная навигация и удобный интерфейс для комфортного взаимодействия.

[vk-marusya-lyart.vercel.app](https://vk-marusya-81740hs27-victoria-s-projects13.vercel.app)

## Запуск

1. Установить зависимости:

   ```bash
   npm install
   ```

2. Запустить приложение:

   ```bash
   npm run dev
   ```
